## About OmniCalc

OmniCalc is an all-in-one calculator application designed to bring everyday calculations and advanced mathematical tools together in one convenient place.

Instead of switching between multiple applications, OmniCalc provides a collection of specialized mathematical tools through a clean, modern, and intuitive interface.

Whether you're a student, developer, professional, or someone who simply needs a reliable calculator, OmniCalc aims to make mathematical work easier and more accessible.

### Why OmniCalc?

* **All-in-one:** Multiple mathematical tools in one application.
* **Offline-first:** Core calculations work without an internet connection.
* **Privacy-focused:** No account, advertisements, or analytics.
* **Modern interface:** Light, dark, and system themes.
* **Convenient:** Calculation history, favorites, and customizable settings.
* **Cross-platform:** Available for Windows and Android.

| Tool                  | Description                                                          |
| --------------------- | -------------------------------------------------------------------- |
| Standard Calculator   | Everyday arithmetic, percentages, memory, and live previews.         |

## How to Use

Getting started with OmniCalc is simple.

### 1. Choose a Tool

Open OmniCalc and browse the home screen.

Each card represents a different mathematical tool. Select the tool you want to use.

### 2. Enter Your Values

Enter your numbers, expressions, equations, or other required information.

### 3. Calculate

Press the equals button or use the relevant calculation controls to obtain your result.

### 4. Explore More

Use the other available tools, save frequently used items to Favorites, and access previous calculations through History.

### Useful Windows Keyboard Shortcuts

| Shortcut       | Action                          |
| -------------- | ------------------------------- |
| `Ctrl + K`     | Search for tools                |
| `Alt + H`      | Return to Home                  |
| `Alt + 1–8`    | Open the first eight home cards |
| `Ctrl + ,`     | Open Settings                   |
| `Enter` or `=` | Calculate                       |

## Privacy & Offline Usage

OmniCalc is designed with privacy and offline functionality in mind.

* No account registration required.
* No advertisements.
* No analytics.
* Calculations and saved data remain on your device.
* Core mathematical tools work offline.
* Optional exchange-rate downloads require an internet connection.

Your calculations and saved information are stored locally rather than synchronized to an external account.
