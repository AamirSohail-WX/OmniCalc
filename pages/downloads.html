Installing

Android

Open the APK, allow installs from your browser or file manager when asked, then install. Requires Android 7.0 or newer. See installation help.

Windows installer

Run the installer. The build is unsigned, so Windows SmartScreen may show a warning: choose More info, then Run anyway.

Windows portable

Save the file anywhere and double-click it. No installation step is needed.

Good to know

  • Download only from this website’s buttons. They are set to the official release files.
